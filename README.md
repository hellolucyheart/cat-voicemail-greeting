One voicemail greeting as recorded by a cat, 107 characters: Nala, at
4 a.m., with an empty bowl, informing the caller that this is entirely
their problem — and to meow after the beep. The joke is specific to
cats (the 4 a.m. food demand), the cat speaks in her own voice, and
the punch lands in the few seconds a caller waits.

## Run it

```sh
python3 main.py
```

Writes the greeting to `/output/entry.txt`. Deterministic: the same
fixed line on every run, no network, no model call, no randomness.
